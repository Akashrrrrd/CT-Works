# Quick Start - Report Download Feature

## 🎯 What's New

A **Download Report** button now appears next to the Calculate button.

---

## 📍 Where to Find It

In the Siemens 7SJ85 Calculator:

```
┌─────────────────────────────────────────────────────────┐
│ Input Parameters │
│ (CT Wiring, VT Wiring, System, Power Line, etc.) │
├─────────────────────────────────────────────────────────┤
│ │
│ [Calculate CT/VT Adequacy] [Download Report] ← NEW │
│ │
└─────────────────────────────────────────────────────────┘
```

---

## 🚀 How to Use

### Step 1: Fill in Parameters
- Adjust CT, System, and Power Line parameters as needed

### Step 2: Calculate
- Click **"Calculate CT/VT Adequacy"**

### Step 3: Download
- Once results appear, click **"Download Report"**
- File saves automatically: `7SJ85_Report_2026-07-21.html`

### Step 4: Open/Share
- Open in browser to view
- Print to PDF
- Share via email
- Include in documentation

---

## 📄 What's in the Report

✅ **Verdict** (Pass/Fail with color coding) 
✅ **All Calculations** (CT, Fault, Burden) 
✅ **Input Parameters** (For reference) 
✅ **Professional Formatting** (Print-ready) 
✅ **Timestamp** (Generation date/time) 
✅ **Document Reference** (Standard Engineering standard info)

---

## 💾 File Format

- **Type:** HTML (self-contained)
- **Size:** ~50-100 KB
- **Name:** `7SJ85_Report_YYYY-MM-DD.html`
- **Opens in:** Any web browser
